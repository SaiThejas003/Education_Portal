# KIT Education Management Portal

This project is a web-based enterprise ERP system built for KalaignarKarunanidhi Institute of Technology. It brings together student tracking, faculty workflows, administrative data, and automated AI analytics into one clean platform.

## What it does

* **For Students:** Keep an eye on attendance percentages, view course materials, submit assignments, check internal exam marks, and read personalized AI study tips.
* **For Faculty:** Manage class rosters, mark daily attendance, post assignments, enter exam scores, and view automated reports flagging students who need extra support.
* **For Administrators:** Track high-level institutional metrics, manage user accounts across departments, and pull performance analytics reports.
* **AI Risk Engine:** Automatically reviews student attendance and grades in the background to highlight attendance deficits or weak subjects early on.

## Tech Stack

* **Frontend:** React, Vite, TypeScript
* **Routing:** React Router (using HashRouter for easy static hosting compatibility)
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **State Management:** React Context API
